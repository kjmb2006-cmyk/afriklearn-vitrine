## 1. Modèle de demande d'autorisation à envoyer au partenaire/client

> Objet : Autorisation d'affichage de votre logo sur notre site institutionnel
>
> Bonjour [Nom du contact],
>
> Dans le cadre de la refonte du site institutionnel d'AFRIK'LEARN Consulting
> (afriklearn-consulting.com), nous souhaiterions mentionner [Nom de l'organisation] parmi
> nos partenaires/clients, avec affichage de votre logo dans la section "Ils nous font
> confiance".
>
> Pourriez-vous nous confirmer votre accord par retour de ce message (e-mail faisant foi), et
> nous transmettre si possible une version haute résolution de votre logo (SVG ou PNG fond
> transparent) ?
>
> Nous restons à votre disposition pour toute question.
>
> Cordialement,
> AFRIK'LEARN Consulting SARL

## 3. Quand transmettre à Claude Code pour intégration

Une fois **au moins un** partenaire avec accord écrit confirmé et fichier logo en main :

1. Fournir le nom de l'organisation (tel qu'il doit apparaître, pour le texte `alt` de l'image)
2. Fournir le fichier logo (SVG de préférence, sinon PNG haute résolution fond transparent)
3. Confirmer que l'accord écrit est bien en main (pas besoin de le transmettre, juste confirmer)

La section "Ils nous font confiance" sera alors créée dans le code avec les logos reçus —
jamais avec des logos de remplacement ou génériques en attendant (CLAUDE.md §0.1 et §13).
